# 心版 · 圣经钥节背诵游戏

给初中生用的经文背诵小游戏，经文为新标点和合本（神版）。整套是一个静态网页，不需要编译。

- **闯关**：一关一节经文（长段落每两节一关）。
  - 普通训练：抄一遍（可跳过）→ 选词 → 拼词 → 找错 → 再选 → 再找 → 填空 → 认出处。
  - 高阶训练：只看出处，默写整节。
  - 过程中经文卡从石版慢慢变成发光的心版（林后 3:3）。
- **测试**：60 秒快问快答，题型有填空、下一句、出处、排序，有连击加分。
- **对战**：两队同屏抢答，或比赛拼整节经文。
  - 平板：两边同时点。
  - 电脑：蓝营按 1–4，橙营按 7–0。
- **心版榜、老师后台、导入经文库**。

## 目录

```
index.html              整个游戏（页面、样式、脚本、经文数据都在这一个文件里）
assets/                 插画（WebP）
supabase/schema.sql     接入 Supabase 时用的数据表和权限
docs/后端交接说明.md     给做系统的人：怎么把“本机保存”换成真正的后台
```

## 本地打开

直接双击 `index.html` 就能玩。插画通过相对路径读取 `assets/`，所以两者要放在一起。

## 部署成网站

这是纯静态页面，放到任何静态托管上都能用：

- **GitHub Pages**：仓库 Settings → Pages → Source 选 `main` 分支根目录，保存后几分钟内生效。
- **Vercel / Netlify**：导入这个仓库，框架选 “Other / 无”，不需要构建命令，发布目录是根目录。

## 账号与数据

- **学生**：在游戏首页用老师发的账号（如 `km01`）和 4 位数字密码登录。闯关进度、每日练习时长、测验成绩会存到数据库，换设备也不丢。也可以选“先当游客玩”，游客的进度只存在那台设备的浏览器里。
- **老师**：打开 `teacher.html`（网站上是 `/xinban/teacher.html`），用邮箱注册、登录。
  - 建班级，粘贴学生名单，一键生成账号和密码，可以复制或打印。
  - **学习情况**：全班一览（今天、近 7 天、累计练习时长，过关数，测验最高分和最近一次），点开每个学生能看到近 30 天的每日时长柱状图、测验分数曲线和每卷书的关卡格子。
  - **学生账号**：重置密码、改名、删除。
- **数据库**：Supabase（项目 `xinban`，新加坡机房），结构见 `supabase/schema.sql`。
  - 每人每天的练习时长只占一行，每关只占一行，每次测验一行，数据量很小。
  - 学生端只能通过登录凭证调用几个函数读写自己的数据，老师只能看到自己建的班级。
  - 练习时长的计算方式：页面在前台、并且最近 2 分钟内有操作才计时，按雅加达时间分天。
- 在 Claude 页面（artifact）里打开时连不了外部数据库，只能当游客玩。
