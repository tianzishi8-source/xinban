# 心版 · 圣经钥节背诵游戏

给初中生用的经文背诵小游戏，经文为新标点和合本（神版）。整套是一个静态网页，不需要编译。

- **闯关**：一关一节经文（长段落每两节一关）。
  - 普通训练：抄一遍（可跳过）→ 选词 → 拼词 → 找错 → 再选 → 再找 → 填空 → 认出处。
  - 高阶训练：只看出处，默写整节。
  - 过程中经文卡从石版慢慢变成发光的心版（林后 3:3）。
- **测试**：60 秒快问快答，题型有填空、下一句、出处、排序，有连击加分。
- **对战**：两队同屏抢答，或比赛拼整节经文。
  - 平板：两边同时点。
  - 电脑：蓝营按 1–4，橙营按 7–0。
- **每日作业**：老师后台顶部为每个班设“作业经文包”和“每天 N 关”。学生每天要先在作业经文包里过完 N 个新关卡（剩下不足 N 关时做完即可），完成前其他经文包的闯关和测试、对战、词汇都锁住；首页有今日作业进度条。“作业检查”里能看到每个学生当天新过了几关。
- **温习摸底**：每天第一次进闯关，从这个经文包已经过的关卡里出约 6 道打字填空（优先出最近学的、星星少的、以前错过的）。答错的关卡在地图上变红，标“温习”；有待温习关卡时不能开新关，重新过一遍就自动解除。“作业检查”里能看到摸底成绩和还没补完的温习关。
- **只能自己打字**：经文不能复制，答题框不能粘贴或拖放；擦掉、挖空的位置只留空白，不留原字的印记，打错时也不会露出正确的字。
- **福音的定义**：在“祷文·信经·福音”里，18 行分三部分；先一行一关，再三行一关，最后第一部分、第三部分整段各一关，共 26 关。
- **心版榜**：登录的同学互相看得到排名。三个榜：星星榜、测验榜（按经文包分开排）、勤练榜，每个榜都有今日、本周、总榜；可看全部同学或只看我的班。最上面显示我的名次和离前一名还差多少。只显示名字、班级和成绩。
- **经文包**（首页“换经文包”）：
  - 书卷：每卷书一个包；只有一两节的小书合成「历史书精选」「诗歌智慧书精选」「先知书精选」「书信精选」。
  - 课程：《基督里的新生命1》《基督里的新生命2》各 12 课。
  - 祷文·信经·福音；搜索。
  - 原来的“资料”题库已并入对应书卷，重复的经文已删去（清单见 `docs/经文包整理_删除清单.md`）。
  - 老师以前用旧名（如“n1 背诵经文·第三课”）设的作业经文包仍然有效，会自动对应到新名字。
- **老师后台、导入经文库**。

## 目录

```
index.html              整个游戏（页面、样式、脚本、经文数据都在这一个文件里）
assets/                 插画（WebP）
supabase/schema.sql     接入 Supabase 时用的数据表和权限
docs/后端交接说明.md     给做系统的人：怎么把“本机保存”换成真正的后台
```

## 本地打开

直接双击 `index.html` 就能玩。插画通过相对路径读取 `assets/`，所以两者要放在一起。

## 部署成网站

这是纯静态页面，放到任何静态托管上都能用：

- **GitHub Pages**：仓库 Settings → Pages → Source 选 `main` 分支根目录，保存后几分钟内生效。
- **Vercel / Netlify**：导入这个仓库，框架选 “Other / 无”，不需要构建命令，发布目录是根目录。

## 账号与数据

- **学生**：在游戏首页用老师发的账号（如 `km01`）和 4 位数字密码登录；也可以点“注册新账号”，自己起账号和密码（账号小写字母开头、4–20 位，不能用“两个字母＋数字”这种老师账号的格式）。自己注册的学生进入老师后台的“自助注册（待分班）”，老师在“学生账号”里点“移到班级”即可分班，学习记录一起带过去。闯关进度、每日练习时长、测验成绩会存到数据库，换设备也不丢。也可以选“先当游客玩”，游客的进度只存在那台设备的浏览器里。
- **老师**：打开 `teacher.html`（网站上是 `/xinban/teacher.html`），用邮箱注册、登录。
  - 建班级，粘贴学生名单，一键生成账号和密码，可以复制或打印。
  - **学习情况**：全班一览（今天、近 7 天、累计练习时长，过关数，测验最高分和最近一次），点开每个学生能看到近 30 天的每日时长柱状图、测验分数曲线和每卷书的关卡格子。
  - **学生账号**：重置密码、改名、删除。
- **数据库**：Supabase（项目 `xinban`，新加坡机房），结构见 `supabase/schema.sql`；自助注册、排行榜的改动见 `supabase/migrations_2026-11-23_*.sql`。不想上榜的班（如老师自己的测试账号）在数据库里把 `classes.hide_rank` 设为 true。
  - 每人每天的练习时长只占一行，每关只占一行，每次测验一行，数据量很小。
  - 学生端只能通过登录凭证调用几个函数读写自己的数据，老师只能看到自己建的班级。
  - 练习时长的计算方式：页面在前台、并且最近 2 分钟内有操作才计时，按雅加达时间分天。
- 在 Claude 页面（artifact）里打开时连不了外部数据库，只能当游客玩。
